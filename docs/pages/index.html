Gamb WP Static Guard

Exporte um site WordPress como HTML estático e confira os arquivos e cabeçalhos da publicação no painel.

Abrir manual Ver versões Código e suporte

O que o plugin faz

  • Exporta para uma pasta do servidor ou um arquivo ZIP.
  • Verifica canonical, indexação, integridade de CSS e entrega de documentos.
  • Gera backups de banco, tema e extensões conforme a configuração disponível.

Requisitos do plugin: WordPress 6.2 ou superior e PHP 7.4 ou superior.
